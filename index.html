Manage your application configurations.

API

Connect your application to the Cloud config API.

Server URL

Enter the URL where your Java server is running.

Get Configs

Retrieve all configs.

GET /api/configs 
GET /api/configs

Save Config

Send a configuration to the Java server. 

POST /api/configs

Content-Type: application/json

{
    "name": "My Config",
    "environment": "Production",
    "data": "{\"enabled\":true}"
}

Upload CFG

Upload a CFG file directly to the server. 

POST /api/configs/upload

Content-Type: multipart/form-data

file = myconfig.cfg

C++ Example

#include <curl/curl.h>

int main()
{
    CURL* curl = curl_easy_init();

    const char* url =
        "http://YOUR-SERVER:8080/api/configs";

    const char* json =
        R"({
            "name": "My Config",
            "environment": "Production",
            "data": "{\"enabled\":true}"
        })";

    struct curl_slist* headers = nullptr;

    headers = curl_slist_append(
        headers,
        "Content-Type: application/json"
    );

    curl_easy_setopt(curl, CURLOPT_URL, url);
    curl_easy_setopt(curl, CURLOPT_HTTPHEADER, headers);
    curl_easy_setopt(curl, CURLOPT_POSTFIELDS, json);

    CURLcode result =
        curl_easy_perform(curl);

    curl_slist_free_all(headers);
    curl_easy_cleanup(curl);

    return result == CURLE_OK ? 0 : 1;
}
